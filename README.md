# EuegneSnake 贪吃蛇

## 项目简介
EuegneSnake 是一个基于 Linux 终端的贪吃蛇游戏，采用 C++ 面向对象编程实现。程序通过 `SnakeGame` 类封装游戏流程、终端渲染、输入处理和碰撞检测，`main.cpp` 只负责创建对象并启动游戏。

本项目实现了：
- 主界面菜单与子菜单（开始、难度、颜色、退出）
- 难度选择影响速度与食物分值
- 多种颜色方案
- 障碍物生成
- 食物随机生成且不会与蛇身或障碍重叠
- 按键控制与加速机制
- 游戏失败后重新开始或退出选项

## 核心代码结构

### `src/main.cpp`
- `main()` 中仅创建 `SnakeGame game`，调用 `game.Run()`。
- 保证入口函数不包含具体游戏逻辑，符合题目“Main 函数中不能出现具体实现操作”的要求。

### `inc/SnakeGame.hpp`
- 定义 `Position` 结构体：`x`、`y` 表示地图坐标。
- 定义 `Direction` 枚举：`Up`、`Down`、`Left`、`Right`。
- 定义 `GameConfig` 结构体：地图大小、基础延迟、得分、颜色字符串等。
- 声明 `SnakeGame` 类及其私有方法：初始化、菜单、绘制、输入、更新、碰撞检测、终端控制等。
- 成员变量包含：蛇身、障碍、食物、方向、分数、难度、运行状态等。

### `src/SnakeGame.cpp`
实现了游戏的全部行为，按功能可分为：
- 构造与默认配置
- 运行流程控制
- 菜单与选项处理
- 初始化与生成逻辑
- 绘制与终端显示
- 输入读取与方向判断
- 游戏更新与碰撞检测
- 终端模式控制

## 运行流程与函数调用关系

1. `main()` → `SnakeGame::Run()`
2. `Run()`
   - `ShowMainMenu()`：显示主菜单并读取用户选项。
   - 启用终端隐藏光标、原始输入模式。
   - `InitializeGame()`：初始化蛇、食物、障碍。
   - 进入主循环：
     - `DrawFrame()`
     - `ProcessInput()`
     - `UpdateGame()`
     - `usleep()` 控制帧率
   - 游戏结束后：恢复终端设置，显示结束界面。
   - `WaitForMenuOption()`：等待用户选择再玩或退出。

### 关键函数说明

#### `InitializeGame()`
- 重置蛇身、障碍物、分数、方向、游戏状态。
- 默认蛇头在地图中心，初始长度 3。
- 调用 `SpawnFood()` 和 `SpawnObstacles()`。

#### `SpawnFood()` / `SpawnObstacles()`
- 通过 `std::rand()` 生成随机坐标。
- `IsPositionAvailable()` 用于避免生成位置与蛇身或障碍物冲突。
- 障碍物数量 = `4 + difficultyLevel`，难度越高障碍越多。

#### `IsPositionAvailable(const Position &pos)`
- 检查坐标是否在边框内。
- 检查是否与当前蛇身重叠。
- 检查是否与已有障碍物重叠。

#### `DrawFrame()`
- 清屏后绘制边框、障碍、食物、蛇身。
- 使用 ANSI 转义序列移动光标到指定位置。
- 在地图下方显示得分、难度、速度说明与退出提示。

#### `ProcessInput()`
- 通过 `ReadKey()` 读取单个按键。
- 支持 `WASD`、大小写方向键、空格、`Q`。
- 如果按与当前方向相同，则开启“加速”模式。
- 如果按与当前运动方向相反，方向不会改变，避免掉头。
- `Q` 可直接结束本局游戏。

#### `UpdateGame()`
- 根据 `moveDirection` 计算下一帧头部位置。
- 调用 `DetectCollision()` 判断是否撞墙、撞身体或撞障碍。
- 若无碰撞，插入新头部；若吃到食物则加分并生成新食物，否则移除尾部实现移动。

#### `DetectCollision(const Position &nextHead)`
- 判断 `nextHead` 是否超出边界。
- 判断是否与当前蛇身重叠。
- 判断是否与障碍物重叠。

#### `SetRawMode(bool enable)` / `ReadKey()`
- `SetRawMode(true)` 将终端设为原始模式：关闭回显与标准行缓冲，设置非阻塞读取。
- `ReadKey()` 使用 `select()` 检测是否有输入，再用 `read()` 读取最多 3 字节。
- 方向键逃逸序列会被识别为 `[<code>`，返回值为 `1000 + <code>`。
- 常规键直接返回 ASCII 码。

## 代码重难点解读

### 1. 终端输入与原始模式
- 项目没有使用第三方库，而是直接操作 `termios` 与 `select()`。
- 这部分是本代码最难的地方：需要处理按键缓冲、非阻塞输入、方向键转义序列和恢复终端状态。
- `SetRawMode(false)` 在游戏退出或暂停后必须调用，否则终端会保留在原始模式，影响后续输入。

### 2. ANSI 控制与渲染
- 使用 `\033[2J\033[H` 清屏、`\033[<y>;<x>H` 定位光标、颜色转义序列对元素着色。
- 终端绘制不是实时图形，而是“逐帧重绘 + 光标定位”，需要保证坐标计算正确。

### 3. 游戏状态管理和碰撞逻辑
- 蛇身由 `std::vector<Position>` 保存，头部始终是 `snakeBody.front()`。
- 通过向前插入新头并按条件弹出尾部实现移动与生长。
- `lastDirection` 用于判断当前方向能否反向，以及“同方向加速”的触发条件。

### 4. 菜单与输入容错
- 所有菜单输入都经过 `std::cin` 校验。
- 若读取失败，会清除输入状态并丢弃缓冲，避免非法输入导致程序卡住。
- 这确保了主菜单和失败后菜单都有良好容错能力。

## 运行与使用说明

### 编译
```bash
mkdir -p build
cd build
cmake ..
cmake --build .
```

### 启动
```bash
./EuegneSnake
```

### 控制键
- `W` / `w` / 向上箭头：向上移动
- `S` / `s` / 向下箭头：向下移动
- `A` / `a` / 向左箭头：向左移动
- `D` / `d` / 向右箭头：向右移动
- 空格键：加速移动
- `Q` / `q`：结束当前局游戏

### 游戏逻辑说明
- 初始蛇身长度为 3，起始位置在画面中央。
- 吃到 `@` 后得分并增长一格。
- 撞到边框 `#`、身体 `O` 或障碍 `*` 游戏结束。
- 难度影响移动速度与每个食物得分。

## 代码改进建议

1. 将逻辑拆分为更多独立模块，如 `Renderer`、`InputManager`、`GameState`。
2. 使用 C++ `<random>` 替换 `std::rand()` 生成随机数，避免重复和更好可控。
3. 改进方向键解析，支持更多终端转义序列。
4. 支持窗口大小自适应，或将地图大小作为配置参数。
5. 添加“暂停”“记录最高分”“音效”“菜单动画”等增强功能。
